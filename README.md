# Organizational Transformation

A shared workspace for understanding market changes, identifying opportunities, and discussing possible businesses.

## How the work flows

1. **Market trends:** What is changing about the world, technology, businesses, and people? What evidence supports or challenges it?
2. **Implications and opportunities:** Who wins or loses, why, where does value move, and what unmet needs emerge? Why can existing providers not meet them?
3. **Solutions and company concepts:** What could address those needs? Is it a company, a service, a feature, an acquisition strategy, or something else?

Trace each proposed solution back to an opportunity and the trends behind it. Several trends can combine into one opportunity; several solutions can address the same opportunity. Revisit earlier assumptions as evidence changes.

## Reading the reports

Download the repository using GitHub’s **Code → Download ZIP**, extract it, and open `trends/index.html` in a browser. Keep the folders together so links to supporting evidence continue to work. The reports can be read offline; external sources require an internet connection. GitHub displays HTML source rather than the rendered report.

## Adding material

1. Save new sources in the research library and record their origin and date.
2. Add evidence and counterevidence to the relevant trend, opportunity, or solution document. Distinguish hypotheses, reported observations, supported findings, and decisions.
3. Link the reasoning across layers; record open questions and what evidence would change the conclusion.
4. Keep meeting preparation, discussion records, decisions, and research follow-up in [notes](notes/README.md).

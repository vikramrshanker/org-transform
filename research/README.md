# Research and evidence

Store new interview notes, reports, analyses, and datasets here. Add subfolders when needed.

- [Research questions](../notes/research-questions.md): what we need to learn and why.
- [Source register](sources.md): where evidence came from.
- [AI capability and adoption evidence](data/ai-capability-adoption/README.md): sources, chart data and update notes for the first research report.
- [Companion trend reports](data/trend-reports/README.md): source records, chart values and update instructions for the other six reports, researched September 21, 2026.
- [Research note template](../templates/research-note.md): a format for new material.

Research supports all three layers: [market trends](../trends/index.html), [implications and opportunities](../opportunities/README.md), and [solutions](../solutions/README.md). Link a finding to each layer it informs without copying the source into every document.

Keep original sources separate from interpretations. Include source dates, limitations, and counterevidence. Original brainstorm transcripts remain in the project root and are linked from the main README.

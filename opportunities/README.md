# 2. Implications and opportunities

As markets change, who wins, who loses, why, and where is an unmet need?

- [Implications map](implications.md): trace trends to affected players and consequences.
- [Opportunity map](opportunity-map.md): compare unmet needs before choosing solutions.
- [Exploratory ideas](exploratory-ideas.md): keep rough or contradictory ideas visible.
- [Opportunity template](../templates/opportunity-brief.md): create a brief when an unmet need deserves deeper examination.

An opportunity describes a need, constraint, or shift in value. A proposed product, service, acquisition strategy, or marketplace belongs in [solutions](../solutions/README.md). Several trends can support one opportunity, and one opportunity can have several possible solutions.
